Inside gdn_conv

Before the delta rule sees q, k and v, each of their 8192 channels passes through a short causal convolution: a weighted sum of the channel's value at this token and at the three tokens before it, with 4 learned weights per channel, then SiLU. It gives the linear-attention layer a little local context of its own. The 16 query and 16 key heads are then L2-normalized, so the recurrence only ever sees unit-length keys. The tokens before a chunk live in a small conv state; conv_save updates it afterwards.

yₜ[c] = SiLU( Σs=0…3 w[c][s] · xt−3+s[c] )  ·  q, k heads: y ← y / √(Σ y² + ε)   // x_u for u < 0 is row 3 + u of the conv state; ε = 1e-6

Why it is built this way

    

      

        
A depthwise convolution: no channel talks to another

        
Each channel has its own 4 weights and sees only its own past, so a thread needs 4 loads of x, one float4 of weights and 4 FMAs, in the same order as ggml's ssm_conv (sum from tap 0). The x values come from the qkvz buffer, where each token's row is 12,288 floats: thread c of the block for token t reads column c of rows t − 3 … t, and the 128 threads of a block read 512 consecutive bytes of each row.

        
The L2 norm needs the whole head, which is why a block is exactly one head: 4 warp butterflies, 4 partials in shared memory, one barrier. The 32 value heads skip it (a block-uniform branch on blockIdx.x).

      

      

        
The conv state and conv_save

        
Positions before the chunk come from the conv state, 3 rows × 8192 channels per layer (96 KB). It is updated by a separate small kernel, conv_save, after gdn_conv: the blocks for tokens 0–2 still read the old rows, and with no ordering between blocks, writing them in the same launch would race.

        
conv_save keeps the last 3 rows of [state; chunk]. When the chunk has fewer than 3 tokens, the old rows shift up; each thread owns one channel and writes rows 0, 1, 2 in order, so it always reads a row before overwriting it. Like the recurrent state, the conv state holds exactly the tokens seen so far: it is part of the chat snapshot.

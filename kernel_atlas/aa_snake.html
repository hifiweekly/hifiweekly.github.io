Inside aa_snake

The soundtrack comes out of BigVGAN, a convolutional vocoder that turns 40 latent frames per second into 32,000 samples per second. Its nonlinearity is SnakeBeta, x + sin²(eαx) / eβ: a periodic bump per channel that lets the network produce tones without learning them from scratch. A pointwise nonlinearity on a sampled signal creates harmonics above the Nyquist frequency, which fold back as audible aliases, so BigVGAN applies it at twice the sample rate: upsample by 2 with a 12-tap low-pass filter, apply the snake, low-pass and drop every second sample. The reference runs those as three operations with a 2×-long signal in between. This kernel does all three per output sample, from 6 input samples, in registers. Both 12-tap filters and every α and β below are the model's own.

y[t] = Σj<12 dn[j] · snake(u[clamp(2t + j − 5)]),   u[n] = Σi x[clamp(i − 5)] · 2·up[n + 15 − 2i],   snake(u) = u + sin²(eαu) / (eβ + 10⁻⁹)   // per channel

Why it is built this way

    

      

        
Recompute instead of storing the 2× signal

        
Output t needs upsampled samples 2t − 5 … 2t + 6, and output t + 1 needs 2t − 3 … 2t + 8: neighbours share 10 of 12, so each u is computed about 6 times. In exchange there is no 2L × C intermediate, which at the last stage would be 59,200 samples × 8 channels written and read twice per activation, 254 activations per video. The extra arithmetic is 72 FMAs and 12 sines per output, from inputs that stay in L1: the whole audio decoder takes 30 ms.

        
The ×2 is in the filter

        
Upsampling by zero-stuffing halves the signal's energy in the pass band, so BigVGAN's UpSample1d multiplies the filtered result by the ratio. stable-diffusion.cpp does the same (depthwise_conv_transpose1d scales by the stride). The kernel computes the plain filter sum, so the host uploads the upsampling taps already doubled; the kernel self-test checks exactly that combination.

      

      

        
sin.approx needs a reduced argument

        
sin.approx.f32 is accurate on [−π, π] and degrades quickly outside. eαu reaches tens in the early stages, so the kernel subtracts the nearest multiple of 2π first, in two parts (6.28125 exactly representable, then 0.0019353), the Cody–Waite reduction, and only then takes the sine. The reference uses sinf; against the float64 NumPy decoder this engine's audio is within 0.46%, the reference's 2.3% (its convolutions run on f16 im2col).

        
Replicate padding

        
Both filters pad by repeating the edge sample, 5 on the left for the input and 5 / 6 for the upsampled signal, the clamps in the formula. Zero padding would put a step at each end of every decoded clip, and the snake would turn it into a click.

        
Where it runs

        
Each of the 7 upsampling stages has 3 residual stacks (kernels 3, 7, 11) of 3 dilated pairs, each convolution preceded by an activation: 18 per stage, 126, plus activation_post: 127 per channel, 254 for stereo. Channels drop from 512 to 8 as the length grows from 185 to 29,600 samples.

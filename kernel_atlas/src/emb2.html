Batched (prompt) kernels A prompt is processed in chunks of up to 128 tokens. The matrices run as tiled GEMMs, so each weight is read from memory once per chunk instead of once per token. Each block computes a 64-row x 32-token tile of Y = X . W^T: per 64-wide step along the inner dimension it dequantizes the weight tile into shared memory (Ws[k][row], f32) next to the activation tile (Xs[token][k], rows padded to 68 floats), then every thread accumulates 4 rows x 2 tokens (threads whose tokens are all past the end of the tile skip that work).

glm46v.ptx - hand-written PTX kernels for GLM-4 (dense, text) inference, made for the language model of GLM-4.6V-Flash (9.4B; GGUF arch glm4). The host (glm46v.c) runs a layer as (T tokens at a time; sizes for the 9.4B: 40 layers, 32 q heads, 2 kv heads, 128 dims, FFN 13696): q, k, v = Wqkv . xn + b (4096 | 256 | 256) mv_q / gemm_q, bias_rope_kv q, k = RoPE on dims 0..63 (NeoX pairs i, i+32) bias_rope_kv (k, v also to the f16 KV cache) y = Wo . softmax(q K^T / sqrt(128)) V attention, quant_q8, mv/gemm x += rmsnorm(y) * post_attention_norm; add_rmsnorm xn = rmsnorm(x) * ffn_norm g|u = Wup . xn (one [2 x 13696] matrix), mv/gemm, swiglu h = silu(g) * u y = Wdown . h mv/gemm x += rmsnorm(y) * post_ffw_norm; add_rmsnorm xn = rmsnorm(x) * (next layer's attn_norm) (the first layer's xn = rmsnorm(x) * attn_norm is rmsnorm) and finally logits = Wout . xn with the last add_rmsnorm's xn = rmsnorm(x) * output_norm, next = argmax. Weights are ggml's quantized blocks (see quant.h); a matrix is a q array and (for some types) an s array, each [rows][a fixed number of bytes per row], laid out so that every load is aligned: Q8_0: q int8 [cols], s = d f16 [cols/32] Q4_1: q = qs [cols/32][16], s = dm f16x2 [cols/32] IQ4_NL: q = qs [cols/32][16], s = d f16 [cols/32] Q4_K, Q5_K, IQ4_XS: the 144 / 176 / 136-byte blocks as stored [cols/256] Q6_K: q = ql | qh | scales (208 bytes) [cols/256], s = d f16 [cols/256] Q3_K: the 110-byte blocks padded to 112 [cols/256] IQ3_S: 112-byte blocks [cols/256], fields reordered: qs[64] signs[32] qh[8] scales[4] d, 2 bytes padding The 9.4B Q8_0 file needs only Q8_0; the other formats let the engine run other quantizations of the model (Q4_K_M, IQ4_XS, ...). Activations entering a matrix are quantized to int8 in blocks of 32 (as llama.cpp does): xq int8 [n] and xds f32x2 [n/32] = {d, d * sum_j q_j}. A weight block with half scales s_0, s_1 and offset m (w = s_h q + m) then contributes d_x (s_0 dot(q_w, q_x)_0 + s_1 dot(q_w, q_x)_1) + m d_x sum(q_x) with exact integer dot products (dp4a in the matrix-vector kernel, int8 tensor-core mma in the GEMM).

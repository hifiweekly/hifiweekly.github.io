(rmsnorm(x) * output_norm), next = argmax. Weight formats (all row-major, a row = one output feature): Q8 : int8 values q[rows][cols] plus one f16 scale per 32 values d[rows][cols/32]; w = q * d. Used for attention and the output head. MXFP4: per 32 values one E8M0 scale byte e[rows][cols/32] and 16 bytes of 4-bit E2M1 codes qs[rows][cols/2]. Inside a block byte j holds value j in its low nibble and value j+16 in its high nibble. The codes decode to twice the E2M1 value (0, 1, 2, 3, 4, 6, 8, 12, negated for codes 8..15), so the scale used is 2^(e-128) = half of 2^(e-127). Q8 matrices multiply f32 activations directly. Activations entering an MXFP4 expert are quantized to Q8 in blocks of 32 (int8 + f32 scale), as llama.cpp does, so those inner products are dp4a integer dot products times (weight scale * activation scale).

Reading a listing

ld.global.f32memorymov.u32move / convertfma.rn.f32arithmeticdp4a / mmadot products, tensor coresbar.synccontrol, compare, warp%r12register (hover: all uses)@%p1predicate, guard%tid.xspecial registerp_xparameterrms_redshared / global arrayLOOPlabel0f3F800000number (hover: float value).reg .f32directive, type// notecomment

Labels, parameters, arrays and functions are links to their definitions; a line number links to that line. Hover a register (or a .func parameter, which PTX uses like one) to mark all of its uses in the function, click it to keep them marked and step through them from the side panel. Hover a hex float such as 0f3FB8AA3B for its value (log₂e), and an instruction for what it does.

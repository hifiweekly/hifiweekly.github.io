Inside geglu

Gemma 3's feed-forward block multiplies the token by one fused matrix that produces the gate and the up projection side by side, 2 × 15360 values. geglu applies GELU to the gate half and multiplies by the up half, giving the 15360 inputs of the down projection. GELU uses the tanh approximation (as in ggml), and tanh itself is built from a single base-2 exponential.

out[t][j] = GELU(g) · u    GELU(g) = ½ g (1 + tanh(√(2/π) · g · (1 + 0.044715 g²)))   // gu[t] = [g: n | u: n], n = 15360

One element, instruction by instruction

Pick g and u and step through the thread's instructions. tanh is computed as sign(y) · (1 − 2 / (e2|y| + 1)). Using |y| keeps the exponential from overflowing for large negative y; the sign is put back with copysign.

Finding g and u from a flat index

      
The grid-stride loop runs over i = 0 … tokens·n − 1, the output elements. Each token's input row holds 2n values, so the thread divides once to find its token, t = i / n, and then the gate sits at gu[i + t·n] and the up value n floats later.

Inside rope_kv

Right after the q, k, v projections, gpt-oss rotates every query and key head by an angle that depends on the token's position (rotary position embedding, RoPE), then writes the token's keys and values into the f16 KV cache. rope_kv does both. A 64-dimensional head has 32 rotation pairs, so one warp rotates one head, and the values need no rotation, only a copy and a conversion to f16.

(x'p, x'p+32) = (xp cos θ − xp+32 sin θ,  xp sin θ + xp+32 cos θ)   // θ = pos · freqp (YaRN), cos and sin pre-scaled by 1.347

2816 threads per token, three jobs

The grid is (11, tokens) × 256 threads. Thread i of a token rotates pair i % 32 of head i / 32 while i < (64 + 8) · 32 = 2304; the 64 query heads come first, then the 8 key heads, which also go to the cache. Threads 2304–2815 copy the 512 values of v. Each cell below is one warp; click one to follow it.

Why it is built this way

    

      

        
NeoX pairs: dims p and p + 32

        
gpt-oss rotates dimension p together with p + 32 (the "NeoX" layout), not neighbors 2p and 2p + 1. With lane = p, the 32 lanes load dims 0–31 in one 128-byte transaction and dims 32–63 in another, and store the same way. No shuffles, no shared memory: each pair is independent.

        
The angles come from a host-made table cs[pos][pair] = {cos, sin}, so the kernel does no transcendental math at all: two loads and four multiplies per pair. The table already includes YaRN's magnitude scale (1 + 0.1 ln 32 ≈ 1.347).

      

      

        
YaRN and the ring buffer

        
gpt-oss was trained at 4096 tokens and stretched to 131,072 with YaRN: the fastest-turning pairs (here 0–8) keep their original frequency, the slowest (18–31) are slowed by the factor 32, and pairs in between blend the two. The angle chart shows the blend.

        
Local layers only attend to the last 128 positions, so their cache is a ring of 128 + batch slots and position pos lands in slot pos % slots. The batch term lets a whole prefill chunk write its keys before attention reads the window of its first token. Global layers keep one slot per position.

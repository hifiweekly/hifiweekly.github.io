Qwen 3.5 · qwen35.ptx · decode: one warp per row, Q8_0 weights × int8 activations

Inside mv_q8_0

The plainest of the four weight formats: 32 signed 8-bit integers and one f16 scale per block. In the Unsloth Q4_1 file it serves only the DeltaNet gates, the stacked 64 × 4096 [β ‖ α] matrix, which decides per head how much to write (β) and how fast to forget (α). When the engine loads the BF16 file, or the Q8_0 file that qwen35_demo quantize writes, every matrix is Q8_0 and this kernel does all of the decoding work. Both operands are int8, so a block is 8 dp4a and one FMA: no nibbles, no offsets.

y[r] = Σb d[r][b] · dₓ[b] · Σj<32 qj · xj + resid[r]   // weight = d · q, q in −127…127; activation = dₓ · x, x int8

One lane, one Q8_0 block

A block is 32 bytes of int8 weights and a 2-byte scale, kept in two arrays (q and d). Step through the lane's loads, the eight dot products and the single float multiply-add.

Why it is built this way

    

      

        
A tiny matrix: launch-bound, not bandwidth-bound

        
[β ‖ α] is 64 rows: 8 thread blocks on a GPU with 56 SMs, 278 KB of weights. It finishes in about 2.5 µs, mostly the cost of starting a kernel. The engine stacks β and α into one matrix so this happens once per DeltaNet layer instead of twice; the 64 outputs go to the ba buffer, which gdn_recur reads as σ(β) and the decay gate.

        
The GGUF keeps these two in Q8_0 even in the 4-bit file: the gates are small and sensitive, and 8 bits cost almost nothing here.

      

      

        
The whole model in Q8_0

        
Loading Qwen3.5-9B-BF16.gguf, the engine quantizes every matrix to Q8_0 with ggml's reference rounding (d = max|w| / 127). The model then takes 8.2 GiB on the GPU instead of 5.0, decoding reads 8.5 GB per token instead of 5, and its logits are closer to the unquantized model; against llama.cpp running the same Q8_0 file the KL is 7.5e-4 to 1.2e-3.

        
Per block the work is the same as mv_q4_1 minus the unpacking and the offset FMA: 34 bytes read for 32 weights, two v4.u32 loads of weights against the same two of activations.
